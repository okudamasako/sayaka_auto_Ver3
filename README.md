# Sayaka Auto Ver3

Threads・Instagram・X向けのSNS投稿文を生成し、
Notionへ蓄積できるWebアプリです。

日付を入力すると、その日の記念日・話題をもとに
SNS運用向けの投稿テーマへ変換し、
SNS投稿文を生成できます。

テーマを手入力して、
任意の内容から投稿文を作成することもできます。

## 主な機能

- Threads投稿文の生成
- Instagram投稿文の生成
- X向け投稿文の生成
- 日付入力による「今日は何の日」テーマ生成
- 投稿テーマの自動変換
- テーマ手入力による投稿生成
- ハッシュタグ生成
- Instagramリール文の生成
- BGM候補の生成
- 画像生成用プロンプトの生成
- Notionデータベースへの保存

## 使用技術

- Next.js
- OpenAI API
- Notion API
- Vercel
